# Опора бухгалтеру

## Как опубликовать на Vercel
1. Создайте аккаунт на https://github.com
2. Создайте новый репозиторий.
3. Загрузите все файлы из этого архива.
4. Зарегистрируйтесь на https://vercel.com
5. Нажмите Add New → Project.
6. Выберите репозиторий и нажмите Deploy.

## Запуск локально
npm install
npm run dev
